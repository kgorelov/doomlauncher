# Paging
Too many menu items don't fit into screen.
We shall have no more than 7 items per page.
PageUp / PageDown to go the previous/next page.
When you go beyond the last item you go the next page, when you go above the first item you go to the previous page.
Also, we need to display the info on what page it is, out of how many. In small font, under the menu.

# Selected engine info
Currently selected engine is displayed right next to the WAD name. It doesn't look appealing, it's visually pulluting the menu.
I'd rather displayed this info in a small font in the botom left corner above the flames. You know, like doom stats OSD (on screen display).

# OSD font
The command we are about to execute must be alligned to the left, must be in the same block of into as the selected engine.
And we should change the font. It must be small but well readable. Something like the original doom on screen display font.
